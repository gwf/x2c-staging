About
One value, many kinds.


A Var holds a number, text, or a collection. Operators and methods let you work with the value it holds, while ordinary C types remain available when you want them.


Run it locally: x2c run examples/love/values.x
Text is something you work with.


Split an HTTP request, select a path component, and format the result. Slices, splitting, interpolation, and joining turn text processing into ordinary expressions.


Strings are immutable values, so transformations produce a result without changing the original.


Run it locally: x2c run examples/love/strings.x
Give a value a name.


Symbols provide named values for states, keys, and choices. An ordered vocabulary also gives related names an order, so a program can describe its domain without relying on unexplained numbers.


Run it locally: x2c run examples/love/symbols.x
lists


cons prepends a value while sharing the original List tail. Equal
Lists share canonical structure, making equality a pointer comparison.
List.map, List.filter, and List.foldl compose without changing their
inputs. Nested literals and destructuring keep the resulting data as
readable as the operations that produce it.


Run it locally: x2c run examples/love/lists.x
arrays


Array combines indexed access, growth, slicing, and functional
operations. Array.copy creates a separate sequence; Array.sort and
Array.reverse mutate it. Assignment shares the object, == compares
contents, and === compares identity. Copies and slices are shallow:
nested objects remain shared.


Run it locally: x2c run examples/love/arrays.x
maps


Map grows as entries are added, with brackets for reads and updates.
Map.getdefault supplies a fallback without inserting; Map.try_get
distinguishes a missing key from a stored zero. Map traversal order is
unspecified, so this example sorts the keys before printing their values.


Run it locally: x2c run examples/love/maps.x
Data you can read.


Describe nested data directly with collection literals. The punctuation shows how the pieces fit together, and expressions supply the values that vary.


Run it locally: x2c run examples/love/literals.x
Read the file. Use its contents.


Read a whole file as text or process its lines one at a time. File methods handle the buffers; ordinary String and collection operations handle the contents.


Run it locally: x2c run examples/love/files.x
methods


Point.new and Point.move give a user-defined type the same calling
style as the built-ins. Type-qualified names let other types define their
own methods without collisions. Dot notation works for both fields and
method calls; the compiler supplies the receiver argument.


Run it locally: x2c run examples/love/methods.x
operators


Existing collections do the storage work; the new type supplies the
meaning. Set.new reuses Map storage. Set.add and Set.mul define union
and intersection, and protocol Map(Set) connects them to + and *.
The operators return new sets, leaving both inputs unchanged.


Run it locally: x2c run examples/magic/operators.x
Make a repeated pattern a construct.


A macro receives syntax and returns syntax. This swap works with different types because it expands into the surrounding program, where the compiler resolves those types.


Run it locally: x2c run examples/magic/macros.x
Transform a function at its definition.


A decorator adds tracing around a function body. The function keeps its ordinary calling interface while the transformation supplies the repeated entry and exit work.


Run it locally: x2c run examples/magic/decorators.x
Give a convention its own syntax.


Turn locking and cleanup into a statement. The decorator introduces the held lock and its deferred release, so the body can concentrate on the operation being protected.


Run it locally: x2c run examples/magic/keywords.x
Compute while the program compiles.


A meta function runs x2c during compilation. Build related tables from one description, then use the generated values in the finished program.


Run it locally: x2c run examples/magic/compile-time.x
Keep a rule editable at runtime.


Evaluate a Lisp expression using a native binding supplied by the host program. The surrounding program stays compiled while the policy remains data that can be changed and evaluated.


Run it locally: x2c run examples/magic/runtime.x
same list


A meta function computes the squares during translation, and a literal and
direct cons calls write (1 4 9) out. Runtime Lisp calculates the squares
on the fly to produce the same List.
All four results compare equal in constant time because they resolve to the
exact same object.


Run it locally: x2c run examples/magic/ways-to-agree.x
counting


File iteration, String.lower, and Map updates count words without
manual buffers or table management. Array.sort_with compares the counts
in each (word count) pair to rank the results: 3 tea, 2 coffee, 1 milk.
Ties sort by word in reverse order.


Run it locally: x2c run examples/power/counting.x
Build an index. Ask it questions.


Collect document words into an index, then combine the indexed results. Maps, Arrays, and iterator operations make the useful structure visible in the program.


Run it locally: x2c run examples/power/indexing.x
Working memory has a home.


An auto scope reclaims temporary storage together when its block ends. Nested scopes let a program finish one file before moving to the next, while keeping results in their intended destination.


Run it locally: x2c run examples/power/scopes.x
Recognize a shape. Rebuild it.


match selects nested List structures and binds their parts. Templates rebuild the result: $ inserts a value and @ splices a sequence.


This small simplifier combines pattern matching and reconstruction without manually indexing every node.


Run it locally: x2c run examples/power/match.x
threads


Thread.start_raw copies each batch’s bytes and launches a native worker.
Both workers start before either Thread.join returns a result; their
partial sums combine to 91. Thread.free releases the finished handles.
The workers need neither shared input pointers nor a shared accumulator.


Run it locally: x2c run examples/power/threads.x
Cleanup and recovery belong together.


A failed read can leave a block without leaving its file open. Cleanup stays beside the resource; the caller handles the failure where it can decide what to do next.


Run it locally: x2c run examples/power/exceptions.x
Choose the representation you need.


Typed collections retain concrete element types while offering familiar collection operations. Count response codes without giving up native numeric storage.


Run it locally: x2c run examples/power/generics.x
Bring a library into the language.


Import PCRE2 under the name rx, compile a pattern, and read named captures. Package types and methods work alongside ordinary x2c Strings, iteration, and scoped cleanup.


Full source.


Run it locally: x2c run examples/power/imports.x
Equal contents. Distinct identities.


Strings, Lists, and Symbols share equal values. Arrays and Maps are mutable objects: two separate Arrays can have equal contents without being the same Array.


== compares contents; === compares identity. String and List keys let you retrieve a Map entry using an independently constructed equal value.


Run it locally: x2c run examples/love/two-kinds.x
Different containers, familiar operations.


Lists, Arrays, and Maps serve different purposes. Their shared operations let you transform a sequence, rank values, and look up a result without rebuilding those operations for each container.


Run it locally: x2c run examples/love/collections.x
Walk the data, name its parts.


foreach walks a container while destructuring gives each part a name. Pattern conditions select the orders that matter, and an iterator chain totals their quantities.


Run it locally: x2c run examples/love/loops.x
Your types join in.


Define the data and behavior of a Point or an Account. Constructors, methods, and generated operations let your own types participate in the same style of code as the built-ins.


Run it locally: x2c run examples/power/classes.x
Small contracts, useful combinations.


A Set built on a Map gains union and intersection through operators. The type is a typedef Map Set: it reuses Map storage and operations while giving the result a vocabulary of its own.


Run it locally: x2c run examples/power/protocols.x
Connect operations without collecting every step.


Iterators select, merge, and enumerate values as they are consumed. Compose the operations around the task, then collect or reduce the result where you need it.


Run it locally: x2c run examples/power/iterators.x
Describe the record once.


Generated record operations keep field mappings, equality, and representation tied to the type declaration. The same fields work with the surrounding collection and serialization operations.


Run it locally: x2c run examples/power/derive.x
Give each worker a job.


Channels connect a producer and consumer. One worker updates the counts, and the caller reads the result after joining. Ownership and communication remain visible in the code.


Run it locally: x2c run examples/power/channels.x
The compiler can describe your types.


Inspect a type’s fields at compile time and generate code that visits them. This is the same general technique behind derived operations: the declaration supplies the information instead of a second handwritten field list.


Run it locally: x2c run examples/magic/fields.x

Recognize handwritten digits.
Train a convolutional network in x2c with the Torch package, then test it on handwriting it has never seen.
Run it locally:
./configure --packages torch
make -C packages/torch builds/mnist
mkdir -p data/mnist
for name in train-images-idx3-ubyte train-labels-idx1-ubyte \
            t10k-images-idx3-ubyte t10k-labels-idx1-ubyte; do
  curl -fL "https://ossci-datasets.s3.amazonaws.com/mnist/$name.gz" | gunzip > "data/mnist/$name"
done
./packages/torch/builds/mnist data/mnist

How this works and what it cannot do
Running programs is unavailable in this build. Use each example's local recipe.
Browser programs stop after 10 seconds and can use up to 256 MB of WebAssembly memory.
Requires WebAssembly Memory64 (Chrome 133+, Firefox 134+); Safari support is checked in your browser. Processes, File.popen, threads, channels, dispatch, pool workers, native TCP sockets, and HTTP servers are unavailable.
