I fucking love to code.

Twenty years of C, Lisp, and a language I couldn't leave alone.

That’s the most honest explanation I can give for x2c.

I’ve been writing some version of this language for about twenty years. This is at least the third incarnation, possibly the fourth, depending on how you count. A small group of friends has been hearing about it for most of that time. Everyone else has been spared until now.

It was what I worked on during vacations, when I was bored, and whenever I could steal enough time to get lost in an idea. It had no customers, no release date, and no particular reason to exist beyond the fact that I loved making it. For a remarkably long time, it was about ninety percent finished.

Prehistory

For decades, I had been evolving a personal programming style in C that nominally sought to make it more like Lisp. At the same time, I wrote Lisp interpreters to make my C code scriptable. The two halves met but never quite meshed.

Even so, the combination was sort of a superpower. It was my own ham-fisted way of mixing paradigms that are often opposed.

The earliest versions of x2c were clearly a C and a Lisp mashed together. To make them one language, the two had to co-evolve. The most important concepts from Lisp needed a C-like syntax, and the C-like language needed at least some dynamic capability.

Each incarnation got closer to being one language instead of two. The compiler was written in its own language, so changing the syntax was often like repairing a jet engine in flight. Progress was slow.

The last ten percent

In the summer of 2026, coding agents finally became useful on x2c. Earlier ones had struggled with a language they hadn’t encountered on the public web. Over a month or two, they helped me finish documentation, expand the tests, and work through the details I had put off for years.

At that point, I could still say I had written the vast majority of the code in both the compiler and the library. Then the agents kept getting better. I stopped delegating only the work I hated and started working with them the way I would with students or colleagues. At first it was intimate and one-on-one. Eventually I was managing fleets of them.

The agents were supposed to help finish the last ten percent. We ended up doing the last ten thousand percent. This is no longer a human-written codebase. But it grew from one where a single, obnoxiously pedantic person wrote at least the first version of everything.

I can’t imagine finishing it any other way. A project like this would normally take many more people and many more years. What felt magical was that the collaboration allowed me to focus on the parts that mattered most to me: the ideas.

It is an odd time to finish and release a new programming language. It’s not clear that people will write much code by hand anymore, and that includes me.

But a programming language is for thinking, and I still have to think. I now delegate the frameworks and APIs I used to memorize. I keep how I understand a problem and how I express it. For that, I want a language that is readable, powerful, fast, expressive, and still small. The code I think in, the code I want to read, and the code I want to use are now all the same language.

And I still fucking love to code.
