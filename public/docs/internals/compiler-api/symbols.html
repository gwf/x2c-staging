Design notes

Sym holds one compiler’s declarations as a stack of scopes searched from inner to outer; its lowest scopes hold file-scope declarations. It issues the binding identity of each declared name, resolves typedef chains and aggregate fields, and records which file-scope names are private. A SymTxn stages the rows a macro binds, so a failed expansion leaves the table as it was.
