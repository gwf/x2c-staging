MapSubInt.enumerate

Iter MapSubInt.enumerate(MapSubInt map, Iter dest)

Initializes dest to yield canonical (key value) Lists in bucket order. The caller owns dest, and the iterator borrows map; both must remain live during traversal. A null dest returns NULL, and a null map is exhausted. Each step boxes both fields and interns two List cells. Each cell belongs to the pool owning its canonical match, which may be an ancestor pool, or to the current pool when newly allocated. Structural mutation invalidates the iterator. Each MapLongDouble pull allocates its long key as a Var in the current Scope; the yielded List and anything retaining it must not outlive that Scope.

Raises: <alloc-fail> or <size-limit> while interning the List, and for MapLongDouble, <alloc-fail> or <bad-enc> while boxing its key. Shared causes do not return from the pull.

Source: lib/substring-map.x

MapSubInt.iter

Iter MapSubInt.iter(MapSubInt map, Iter dest)

Initializes dest as a single-pass iterator over boxed values. The caller owns dest, and the iterator borrows map; both must remain live during traversal. A null dest returns NULL. Values follow bucket order, a null map is exhausted, and structural mutation invalidates the iterator.

Source: lib/substring-map.x

MapSubInt.keys

Iter MapSubInt.keys(MapSubInt map, Iter dest)

Initializes dest as a single-pass iterator over boxed keys. The caller owns dest, and the iterator borrows map; both must remain live during traversal. A null dest returns NULL. Keys follow bucket order, a null map is exhausted, and structural mutation invalidates the iterator. MapIntInt and both String-keyed families box keys without allocation. Each MapLongDouble pull allocates its long key as a Var in the current Scope; the yielded Var and anything retaining it must not outlive that Scope.

Raises: MapLongDouble iteration may raise <alloc-fail> or <bad-enc> while boxing a key.

Source: lib/substring-map.x

MapSubInt.move_to

void MapSubInt.move_to(MapSubInt map, Scope *destination)

Moves the record, backing Blocks, and nullable owned contents together. Pointers and references remain unchanged. The destination slot acquires a scope if empty. NULL maps do nothing.

Raises: <bad-arg> for a NULL destination slot, or <alloc-fail> while creating its scope. Those failures leave ownership unchanged.

Source: lib/substring-map.x

MapSubInt.scope

Scope MapSubInt.scope(MapSubInt map)

Acquires the Map’s scope for explicitly owned contents. Created lazily beneath the record’s owner, this scope excludes the record and backing Blocks. Stored references remain borrowed unless explicitly moved into it. NULL returns NULL.

Raises: <alloc-fail> when creating the scope.

Source: lib/substring-map.x

MapSubInt.new_capacity

MapSubInt MapSubInt.new_capacity(unsigned capacity)

Creates an empty count table with exactly capacity buckets in the current Scope. Presizing for the expected number of distinct words avoids regrowth; the table still grows past three-quarters full.

Raises: <bad-arg> unless capacity is a power of two of at least two.

Source: lib/substring-map.x

MapSubIntstructA scope-owned count table that borrows Substr keys.

MapSubInt

typedef struct MapSubInt { Scope scope, Bytes hashes, entries; unsigned used, capacity, mask; } *MapSubInt

A scope-owned count table that borrows Substr keys. Keep every source String alive and unchanged until the table’s final use. Counting copies only the view; strings() materializes each unique key once. Context export preserves the table and exports the source Strings used by its views.
