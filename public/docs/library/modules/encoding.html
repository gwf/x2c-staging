Iter String.code_points(String s, Iter dest)

Initializes dest as a lazy iterator over the code points of s, each yielded as an int, so foreach (int point in s.code_points()) walks them. The iterator borrows s.

String

String.try_next_code_point

int String.try_next_code_point(String text, int &cursor, int &point)

Decodes the code point that starts at byte cursor of text into point, advances cursor past it, and returns one. At the end of text, or for a negative cursor, it returns zero and changes nothing.

#include "encoding.x"
int main(void) {
String text = "na\xc3\xafve";
int cursor = 0, point;
while (text.try_next_code_point(cursor, point))
  printf("U+%04X ends at byte %d\n", point, cursor);
  return 0;
}

Raises: <malformed> with cursor as the offset when the bytes there are not a well-formed UTF-8 sequence.

Source: lib/encoding.x

Design notes

A String holds bytes. The UTF-8 operations read and write the code points those bytes encode, and the byte encodings turn any bytes into ASCII text and back. A String cannot hold a NUL byte, so a decoder that returns a String raises <malformed> for one, and its _bytes form returns a Block of 1-byte elements instead. Invalid input raises <malformed> with the operation, a reason, and the input byte offset.
