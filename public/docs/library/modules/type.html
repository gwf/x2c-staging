Type.discards_qualifiers

int Type.discards_qualifiers(Type source, Type target)

Returns whether handing a source value to a target declaration would silently drop a qualifier the target does not keep. The leading qualifiers of each type describe the copied value, not what it points at, so only the deeper levels are compared. Callers use this where the two types are otherwise the same, or where one points at void, which has no deeper levels to compare; a conversion through a converter function copies instead of aliasing.

Type.numeric_literal

Type Type.numeric_literal(String text, int floating)

Returns the native type selected by a validated numeric token. floating selects floating suffix rules; an integer outside all supported native families returns NULL. A signed data token includes its sign when selecting a family, so a signed minimum fits that family.
